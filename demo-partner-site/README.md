# Demo partner site

A neutral "Demo Learning Platform" page (plain static HTML) that shows a partner embedding
ACCESSFLOW with a single script tag. It deliberately does not imitate Savanna or any real
organisation's branding.

Built in **Phase 8**, after the REST API foundations are in place. It will be served from a
**different origin** than ACCESSFLOW so origin checks, `frame-ancestors`, and the new-tab
fallback are tested realistically.
