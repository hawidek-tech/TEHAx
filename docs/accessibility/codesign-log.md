# Co-design log

A co-designer with lived experience of disability reviews the work **in every phase**, not only at the end.
Each finding is recorded with the action taken.

| Phase | Planned co-design focus |
|---|---|
| 0 | Not applicable (no user-facing features). Recruit co-designers and agree how sessions will run. |
| 2 | Preferences and Accessibility Preview: does each setting help? |
| 3 | Form engine: one question per screen, voice input, read-aloud, error messages |
| 4 | Registration journey and identity routes, in the co-designer's preferred language |
| 5 | Profile, CV upload, consent wording |
| 6 | Employer accommodation form (employer co-designer if available) |
| 7 | Full journey end to end |
| 8 | Embedded components on the demo partner site |
