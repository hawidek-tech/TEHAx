# ACCESSFLOW REST API

- Base path: `/api/v1`
- Phase 0 endpoint: `GET /api/v1/system/info` returns `{ "name", "version", "apiVersion" }`
- Health: `GET /actuator/health` returns `{ "status": "UP" }` with no details

From Phase 1, the OpenAPI document is generated by springdoc-openapi, with interactive docs served by the
backend. Integration examples are added per feature and finalised in Phase 9.
